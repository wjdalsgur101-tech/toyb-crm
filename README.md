# TOYB 영업 CRM (대표자 전용)

영업 리드 DB·소통 히스토리를 관리하는 내부 웹 앱입니다.
접속에는 잠금 비밀번호가 필요하며, 리드 데이터는 AES-256-GCM으로 암호화되어 저장됩니다.

- 접속: https://wjdalsgur101-tech.github.io/toyb-crm/
- 정적 파일만으로 동작합니다(서버·빌드 없음). `main` 브랜치 루트가 그대로 배포됩니다.
- 이 저장소에는 개인정보 원문이 평문으로 들어 있지 않습니다. 암호문(`data.enc.json`)만 포함됩니다.
